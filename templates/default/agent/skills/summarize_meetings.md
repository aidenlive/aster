# Summarizing meeting notes

When asked to summarize meeting notes:

1. Read the full notes before writing anything.
2. Produce three sections, in this order:
   - **Summary** — 3 sentences max, plain language.
   - **Decisions** — bullet list; only things actually decided.
   - **Action items** — `owner: task (due date if stated)`.
3. Never invent owners, dates, or decisions that are not in the notes.
4. If the notes are too fragmentary to summarize, say so and list what is missing.
